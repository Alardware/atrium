À propos

Atrium 1.0.0 — tableau de bord auto-hébergé.
Application autonome : un conteneur sert l'interface, stocke la configuration et relaie les appels vers les API de vos services.

Intégrations — chacune est optionnelle et se configure sur la fiche de son application :
Plex (sessions en cours) · Unraid (GraphQL) · UniFi (Network API) · Home Assistant (domotique, lecteurs, mises à jour) · sonde HTTP pour l'état en ligne de n'importe quelle app.

Configuration : /config/atrium.json dans le conteneur.
